# 完整工程交付说明

版本标识：1.0.0rc1，2026-10-06。面向个人自用、基础AI应用。不是已在用户Mac或真实供应商上线，也不是无条件的“全部V1现场验收通过”。原始首版之外的工具/结构化输出/多租户/HA/自研网页没有加入本次范围。

## 相比 V0.2，实际补齐了什么

1. **可用的流式路径。** 不改上游安装包，使用官方SDK窄适配解决独立拒绝、文字后拒绝、合法空流和尾部传输失败。旧native流不再靠示例false保护，而由生产schema明确禁止。
2. **真实来源的用量。** 测试发现SDK也会把bool/数字字符串/浮点强制变整数；改用官方SDK公开已解码原始对象校验。合法完整三项才认证，其他unknown；公共流usage仍不开放。
3. **慢读不再卡死。** 总deadline后的EOF/错误发送、审计收尾和上游close分别有界；真实TCP完全不读的客户端也会释放本地并发槽。
4. **首个基础应用打通。** 附带SDK应用经过实际Proxy/PG/合成上游，非流/流/错误/取消通过；客户端独立16包hash锁，不要求商业IDE。
5. **诊断真正可排障。** 新增当时的候选排除、尝试耗时/首事件、重试/冷却/HTTP状态、组合筛选、稳定游标、0600脱敏导出；清理失败会显示不ready。
6. **保留期不只清一张表。** 明确清理原生daily聚合，关闭非必要spend/audit更新；Nginx默认不另存请求日志，鉴权/撤销与备份按独立生命周期。
7. **恢复不再只靠手工记忆。** 独立撤销意图账本、备份checkpoint、高水位和原生重放；实际旧备份复活key后验证恢复拒绝。失败pg_restore事务回滚、未完成migration和镜像/schema不兼容拒绝均有独立证据。
8. **维护目标与部署组合一致。** 所有实际运维显式production/mock、私有env、Docker目标；生产维护保持受控出口/provider secret overlays并核对运行配置，不能base-only误重建。
9. **数据库不再以超级用户日常运行。** 四个独立SCRAM身份；runtime只DML、backup只SELECT、migrate非超级用户；漂移TEMP权限同样拒绝。
10. **真实启用有完整代码路径。** 固定官方镜像索引/双架构摘要，维护中的Squid7.7精确CONNECT与私网拒绝，provider只读文件式凭据；默认拒绝所有真实目标，不拆网络隔离凑通。

## 首次上手复核追加修正

- 0400/0600宿主secret不能假设容器非root UID能读。新增严格的初始私有tmpfs/短暂属主读取与永久降权桥；不建议chmod0644，实际跨UID/Docker仍列现场验收。
- 新key文件绑定目标和账本身份，错环境撤销在请求前拒绝；旧无绑定文件必须先在明确实例核验后迁移，不把错误实例的404当撤销成功。
- 示例可直接用--key-file私密读取，缺失/不安全/深度畸形文件不给环境fallback或traceback；不再要求把key复制进shell历史。
- 完整回归发现原生二次lifespan会重复注册同一个Guard。bootstrap明确禁止同进程二次构造，标准runner将两适配器放到新进程并合并全部原case；没有跳过失败来凑通过。
- 时限结果以monotonic核对，避免原生同步代码拖延asyncio计时回调后发出迟到200/503；测试分别预热普通和流式懒加载。连续SSE用例改为首事件即有正文、2秒配置预算内持续送块且真实终态远在预算外，仍严格断言配置deadline加固定450ms余量；生产90秒不变，其他原故障与安全断言保留。

- 第二轮整合还发现原生key槽在外层非流式deadline后残留一小时。补调用锁定v3自身的slot-ID幂等清理，保持key1/2契约；同key多轮超时/取消、并发不双释放、恢复旧key反复deadline后成功都有实证。没有清私有计数或用换key绕过。

## 操作上的兼容变化

- 默认mock使用policy.sdk.mock.yaml；policy.mock.yaml保留旧原生路径回归
- 原旧共享DB用户/密码配置不可直接复用；独立角色用于新卷，旧卷迁移必须另行核对
- key/维护工具需显式目标、私有env和独立账本；旧format1备份不具备新恢复护栏，自动恢复拒绝
- 发布/恢复绑定原生migration、镜像和Compose组合；未知/跨schema降级不能用确认flag跳过
- 原有V0.1/V0.2源码清单均重新比对，全部hash不变

当前操作以 [Mac手册](mac-setup.md) 和 [运维手册](operations-complete.md) 为准，旧发布说明只作历史。
